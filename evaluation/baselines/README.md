# Hackathon baselines

These four CSVs are nearest-player baseline predictions with no smoothing or
±1, ±2, and ±5 second majority smoothing. The app uses them for the evaluation table.
They contain algorithmic predictions, not ground truth.

Our upload-ready CSV is generated at `model/our_model.csv`. See the root
[submission commands](../../README.md#run) and the
[hackathon repository](https://github.com/hadisotudeh/more-than-a-hack-2027)
for the original baseline implementation and scoring rules.
